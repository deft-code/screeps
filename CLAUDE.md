# Screeps AI

Game AI for [Screeps](https://screeps.com), written in TypeScript (with some
legacy plain-JS modules still in `src/`). Compiled to `distjs/` and pushed to the
Screeps server via `gulp-screeps`.

Planning docs and task notes for this project are kept separately in `~/screeps`
(not this repo) — check there for prior session context before starting new work.

## Build & deploy (gulpfile.js)

- `gulp compile` — compiles `src/**/*` (TS + passthrough JS) to `distjs/` via
  `gulp-typescript`, and writes external source maps to a sibling `sourcemaps/`
  dir (see "Source maps" below). This is a dependency of every deploy task.
- `gulp deploy` — compiles, then pushes `distjs/*.js` to the default branch.
- `gulp ptr` — compiles, then pushes to the PTR server.
- `gulp season` — compiles, then pushes to the `/season` branch/path.
- `gulp sim` — pushes `src/*.js` directly to the `sim` branch (no compile step;
  legacy/plain-JS only).
- `gulp watch` / `watchPtr` / `watchSeason` / `watchCompile` — re-run the
  corresponding task on every change under `src/`.
- `gulp consoleLog` — connects to the Screeps console websocket, records
  output for a fixed window (`SCREEPS_CONSOLE_SECONDS`, default 60s) from
  `SCREEPS_WORLD` (`season`/`ptr`/`mmo`, default `season`), and saves it to
  `logs/`. Screeps only streams console output live — there's no history API.
- `gulp decodeStack` — decodes a captured Screeps stack trace back to original
  `.ts` source locations. Usage:
  `npx gulp decodeStack --stack "process:60:50 job.hub:12:3"`
- `gulp market` / `money` / `fetch` — one-off scripts hitting the Screeps HTTP
  API (market stats, money history, fetching currently-live code from the
  server into `src/`).

Credentials live in `credentials.js` (gitignored); `blank_credentials.js` is the
template.

## Source maps

`tsconfig.json`'s `inlineSourceMap`/`inlineSources` options are silently
ignored by `gulp-typescript` (v3.2.4) — it doesn't support sourcemap-related
`tsconfig.json` options at all. Sourcemaps are instead wired up explicitly in
the `compile` task via `gulp-sourcemaps`, writing external `.js.map` files to
`sourcemaps/` (sibling to `distjs/`, gitignored, regenerated every compile).

This keeps `distjs/*.js` — what actually gets pushed to Screeps by
`deploy`/`ptr`/`season` — exactly the runtime logic with no
`//# sourceMappingURL` comments or map data (`addComment: false` in the
`compile` task), since Screeps enforces per-branch code size limits and
nothing server-side can use the maps anyway.

Use `gulp decodeStack` to turn a Screeps exception (`module:line:col`) into
the original source location instead of hand-matching compiled output against
`src/`.

## Structure

- `src/` — all game logic. Mix of `.ts` (actively maintained) and legacy `.js`
  files; both are compiled/passed through by the `compile` task
  (`allowJs: true` in `tsconfig.json`).
- `Traveler/`, `murmurhash-js/` — git submodules (see `.gitmodules`).
- `distjs/` — compiled output, gitignored, regenerated by `compile`.
- `sourcemaps/` — source maps for `distjs/`, gitignored, regenerated by `compile`.
- `logs/` — captured console output from `gulp consoleLog`, gitignored.
